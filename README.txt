---
Installation
---
1. Download and install [UMF](https://umodframework.com/download).
2. Download the [latest release](https://placeholder.com/releases) of this mod.
3. Place the downloaded .umfmod file in the uModFrameork/Mods folder of the directory where UMF is installed.
4. Run the game.

Optional:

Place the downloader SRSavestateLoaderSaves folder in Slime Rancher's persistent data folder (e.x. C:\Users\\[NAME]\AppData\LocalLow\Monomi Park\Slime Rancher) and replace duplicate files if needed.

---
Usage
---
* To load the current save, press the loadSave key (default U).
* To change the current save, press the switchSave key (default N) and select the new save.
* To create a new save, press the newSave key (default O) and insert the name of the new save. The name may not be empty and may not share the name of another save.
* Hotkeys can be configured in the UMF settings (Shift+F10 in game).
* To import a save, paste the .sav file into the SRSavestateLoaderSaves folder in the Slime Rancher persistent data folder (e.x. C:\Users\\[NAME]\AppData\LocalLow\Monomi Park\Slime Rancher).

Open Source Instructions for Users:
---
 1. Install Visual Studio 2017 or higher.
 2. Install Slime Rancher.
 3. Install UMF (uMod Framework) v0.53.9 or higher into the game.
 4. Clone or download this project.
 5. Edit GamePaths.xml and change the paths to where your game is installed.
 6. Load the project up in Visual Studio by double clicking SRSavestateLoader.sln.
